# Como contribuir

1. Abra uma issue descrevendo problema ou melhoria.
2. Crie uma branch a partir de `main`.
3. Mantenha a alteração pequena e focada.
4. Inclua testes para mudanças de comportamento.
5. Rode `npm run check` e `npm test`.
6. Abra um Pull Request explicando motivação, impacto e validação.

Não inclua logs reais com credenciais, dados pessoais, informações corporativas ou segredos.
